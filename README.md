# task-2: Stock Portfolio Tracker

CodeAlpha Python Programming Internship - Task 2.

A simple tracker that calculates total investment from hardcoded stock prices.

## Features
- Hardcoded price dictionary (AAPL, TSLA, GOOGL, MSFT, AMZN)
- User enters stock names and quantities
- Displays total investment value
- Optionally saves the result to `.txt` or `.csv`

## Run
```
python stock_tracker.py
```
Requires Python 3.8+ (no external libraries).

## Concepts Used
dictionary, input/output, arithmetic, file handling, `csv`
